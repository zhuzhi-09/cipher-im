# cipher-im · 端到端加密即时通信

> 自托管的端到端加密即时通信：消息在离开设备前加密，服务器只转发密文。

> [!WARNING]
> **未经专业安全审计。** 加密协议参照 Signal（X3DH + 双棘轮 + Sender Key）自行实现，有几处有意的差异（见 [`docs/SECURITY.md`](docs/SECURITY.md)）。
> 适合自己和熟人小范围使用、学习和审阅；请不要把它当成经过验证的安全产品用在高风险场景。

- **形态**：Web / PWA（浏览器打开即用，可加到手机主屏）；原生客户端（Flutter）开发中
- **分工**：Web 端只保留基础聊天功能（单聊、群聊、文件、安全码、漫游、通知）；后续高级功能只做进原生客户端
- **外观**：扁平极简（Linear 风），浅色 / 深色双主题，默认跟随系统，可在设置里固定
- **实测**：加密内核 39 项自测、端到端联测 18 项、浏览器 UI 冒烟 12 项、保留期清理 8 项、主题系统 11 项，全绿

## 一句话架构

```
浏览器/手机浏览器 ──WSS──► Node 服务端（SQLite）  ◄── 只存密文与元数据
        │
        └─ 私钥、会话状态、明文日志都在本机，用登录口令 PBKDF2+AES-GCM 加密后存 IndexedDB
```

- 加密：X3DH 协商 + Double Ratchet（前向保密、后向自愈、乱序容忍）+ 群组 Sender Key
- 账号：Ed25519 身份签名 + X25519 DH，一台设备一套密钥，服务端只收公钥
- 存储：服务端 14 天留存（消息/文件密文），本机加密日志长期保留
- 传输：必须 HTTPS/WSS（浏览器只在安全上下文提供 `crypto.subtle`）

## 怎么跑（本机 / 云电脑开发）

```bash
bash scripts/setup.sh     # 装依赖（幂等）
bash scripts/build.sh     # 构建服务端 + 前端
bash scripts/run.sh       # 起服务，默认只听 127.0.0.1:8099（开发用邀请码 dev-code）
```

浏览器访问 `http://127.0.0.1:8099`。**注意**：如果你从另一台机器按 IP 访问（非 localhost、非 https），浏览器会禁用 WebCrypto，加密层无法启动——请用 SSH 端口转发或 HTTPS。

在远程开发机上跑时，用端口转发到本机：

```bash
ssh -L 8099:127.0.0.1:8099 <你的开发机>
# 然后本机浏览器打开 http://localhost:8099
```

见 [`docs/DEPLOY.md`](docs/DEPLOY.md)。一句话：把发布包传上去，`INVITE_CODE=你的邀请码 DOMAIN=你的域名 bash install.sh` 即可（两个都没有默认值，不给就退出）（自动装 Node 22、systemd、Caddy 反代，且对 Caddyfile 先备份再校验）。

## 功能清单

- [x] 账号注册 / 登录（本机新设备自动生成密钥）
- [x] 单聊：X3DH + 双棘轮，多设备各收一份
- [x] 群聊：Sender Key 分发，成员变动自动轮换
- [x] 文件发送（客户端加密后上传，服务端只存密文）
- [x] 离线消息队列、已读回执、输入中提示
- [x] 安全码（60 位）核对防中间人，带信任状态机（未核对 / 已验证 / 已变更，变更只告警不阻断）
- [x] 本地密钥库加密持久化、刷新后可解锁继续用
- [x] 同账号跨设备漫游：账号级漫游密钥 + 每账号历史副本，新设备用口令解封后补回 14 天历史
- [x] 单文件上限 30MB，超过服务端 413 拒收（客户端先拦一次，省得白传）
- [x] 服务端 14 天保留期自动清理
- [x] PWA（可加到手机/桌面主屏，无商店安装）
- [x] 新消息通知（Web Push）：页面不在前台时弹系统通知，标题和主屏图标显示未读数；通知只写「你有新消息」，不含内容和发送者
- [x] 外观：浅色 / 深色 / 跟随系统（刷新无闪色，弹窗与图标同步变色）
- [ ] 桌面外壳（Tauri/Electron）—— 本机无 GUI，按约定跳过
- [ ] 安卓 APK（Capacitor）—— 放最后，本机只能出包不能跑模拟器

## 准入控制（部署到公网前必看）

默认 **fail closed**：没配 `INVITE_CODE` 就完全不开放注册。

| 环境变量 | 默认 | 作用 |
|---|---|---|
| `INVITE_CODE` | 空（= 关闭注册） | 注册邀请码，多个用逗号分隔；服务端只留 sha256 |
| `REGISTER_PER_HOUR` | `3` | 每 IP 每小时注册上限（令牌桶） |
| `LOGIN_PER_MIN` | `10` | 每 IP 每分钟登录尝试上限（防口令爆破） |
| `BLOB_QUOTA_MB` | `200` | 每个账号的文件密文总量上限 |
| `BLOB_TOTAL_MB` | `2000` | 全站文件密文总量上限，超了拒新上传 |
| `VAPID_SUBJECT` | 第一次订阅时的站点地址 | Web Push 的联系地址（`mailto:` 或 `https:`），一般不用配 |
| `RETENTION_DAYS` | `14` | 消息/文件/漫游副本的保留期 |
| `HOST` | `127.0.0.1` | 监听地址；公网入口交给 Caddy，别直接暴露 |

另外两处：

- **WS 令牌不再放 URL**：连接建立后首帧发 `{t:'auth', token}`，服务端回 `authOk` 才认——避免反代的 access log 把长期令牌抄下来存盘。
- **注册/登录/上传都走内存令牌桶**，单进程够用，不依赖 Redis；闲置桶每 10 分钟清一次。

实测见 `node scripts/gate-check.mjs`（自带临时服务端，把限流和配额调到边界值，15 项断言）。

## 新消息通知（Web Push）

- 设置 →「新消息通知」→ 开启。服务端只在这台设备**没有前台页面**时推送（客户端用 `presence` 上报前台/后台），同一设备同一会话 5 秒内只推一次
- 推送内容只有会话 id，没有发送者、群名和密文——推送要经过 Apple / Google / 微软的服务器
- 订阅地址只接受 Apple、FCM、WNS、Mozilla 四家推送服务的域名，防止订阅接口被当成 SSRF 跳板
- VAPID 密钥首次启动时生成在 `DATA_DIR/vapid.json`，**别删**：换了密钥，所有设备都得重新开启通知
- 能不能收到看设备：iPhone 要「添加到主屏幕」后从主屏打开（iOS 16.4+）；电脑用 Edge 稳，Chrome 要能连上 Google；没有谷歌服务的国产安卓基本收不到
- 实测：`node scripts/push-check.mjs`（自带临时服务端，`PUSH_DRY_RUN=1` 只记日志不真发，35 项断言）

## 跨设备漫游（怎么用、边界在哪）

换设备登录时，会为你生成一套**新的身份密钥**（端到端加密不共享旧设备私钥）。历史靠另一套东西补：

1. 每个账号有一对 X25519 **漫游密钥**。私钥用账号口令 → PBKDF2(200k) 封起来存服务端，服务端没有口令解不开。
2. 发消息时，发送方用**收件账号的漫游公钥**再封一份明文副本（直聊封自己 + 对端，群聊封全体成员），存在服务端 `hist`。
3. 新设备输对口令后自动解封漫游私钥，打开会话就往回拉副本，解出来合并进本地日志（按消息 id 去重）。
4. 设置里有**漫游设备白名单**：可撤销某台设备（删白名单 + 作废它的 token，直接踢下线）。

边界（`docs/SECURITY.md` 有完整版）：副本和消息同寿命，**只留 14 天**；撤销只能拦住「以后再拉」，
已经下载到那台设备上的内容收不回来；被撤销的设备若再拿口令登录，会重新获得权限——要彻底失效得换口令（还没做改口令）。

## 安全码信任状态机

- 每台对端设备列一张安全码，状态三态：**未核对 / 已验证 / 已变更**
- 点「标记已验证」把当时的指纹写进加密密钥库，重启、换设备后仍然记得
- 如果之后对端那台设备的公钥变了，会话顶部出现告警条，状态自动变「已变更」——**只告警，不阻断发送**，你可以重新核对后再标为已验证
- 纯逻辑在 `src/shared/crypto/trust.ts`，UI 在 `App.tsx` 的 `SafetyModal`

## 界面约定（改样式前先看这段）

- 层次只用 1px 发丝线与底色微差，**不加阴影**；阴影只留给弹窗和 toast
- 只有一个强调色（浅色 `#2563EB` / 深色 `#6E9CFF`），只出现在状态点、未读角标、焦点环、输入中提示
- 自己的消息气泡在浅色下是近黑、深色下是近白（反相配对），对方消息用白/深灰 + 细线
- 图标一律走 `src/web/icons.tsx` 的线描 SVG，禁止再引入 emoji 或图标字体
- 输入框一行起步，随内容长高，封顶 `min(158px, 30vh)`（约 6 行）后转为框内滚动，**不允许涨到全屏**
- 新增颜色必须同时给 `:root` 和 `:root[data-theme='dark']` 两套值，否则深色下会露白
